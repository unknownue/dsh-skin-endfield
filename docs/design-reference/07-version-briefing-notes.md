## 1. 这个页面是什么基调

深色工业底 + **暖金**高亮 + 大幅美术图出血，界面骨架仍是终末地那套：直角、工程标注、`//` 区块前缀、小字宽距拉丁标签。
注意区分两件事：**版本内容**（丹青渡 = 水墨主题的区域/角色美术）与 **界面 chrome**（仍是黑 + 金字语言）。本皮肤要抄的是后者，不是水墨美术。

实测调色板（[实测] 页面内计算色出现次数）：

| 色 | 出现 | 用途（目视对应） |
|----|------|------------------|
| `#FFFFFF` / `rgba(255,255,255,.92)` | 141 / 27 | 正文与标签墨色；`.92` 是非激活行文字 |
| `#151515` / `#111` | 少量 | 页面底、卡片底 |
| `#FFE36B` / `#F1CA41` | 10 / 5 | 暖金：激活行底、分隔线、装饰块 |
| `#00FFA2` | 4 | 薄荷（系统色/成功提示）—— **与本皮肤默认 Accent 同值** |
| `#FF00F0` / `#FFFF21` / `#F7D654` / `#C9D255` | 各 2–4 | HUD 十字标记、状态点、稀有度色 |
| `#939393` / `#D0D0D0` / `#E1E1E0` / `#4E4E4E` | 3–8 | 次级灰阶 |

圆角（[实测]）：`0px` 占绝对多数（各视图 121–202 个元素），另有 `5.05px`（列表行）、`2.5–3.33px`（按钮）、`50%`（圆形箭头钮、状态胶囊）。
→ **直角为默认，圆角只给"行/按钮/圆形控件"，且都很小** —— 与本皮肤一致，说明现在这套直角语言没有走偏。

字体：页面没有 `@font-face`，`font-family` 只有一个变量 `var(--briefing-language-font)`，实测落到系统 `HarmonyOS_Sans_SC`。
→ **不抄**（版权 + 与皮肤已有的 Jost / Michroma / JetBrains Mono 角色分工重复）。

动效（[官方源码]）：入场统一 `cubic-bezier(.22,1,.36,1)`，时长 .3–.45s，逐个延迟 15–52%；没有弹性/回弹曲线。

## 2.5 加载屏（boot）：那个"终端"其实是一张会滑动的图

**观测方法**（两种，都留了证据）：

1. 常规网络下每 40–90ms 采样一次 `innerText` / 进度计数器，并在 120ms、600ms、1s、2s、4s、7s 各截一张图；
2. 用 CDP `Network.emulateNetworkConditions` 把下行限到 120 KB/s，让加载屏**停住 60 秒**，每 250ms 采 `transform` / `opacity`，每 25 个采样截一张图。

证据文件：`assets/screenshots/version-briefing/boot/`（`timeline.json`、`info-timeline.json`、`loading-dom.json`、`loading-strips.json`、`slow-timeline.json`，以及 `t*ms.png` / `burst-*.png` / `slow-*.png` 截图）。

**时间线**（[实测]，常规网络）：

| 时刻 | 发生什么 |
|------|----------|
| ~0.45s | `#root` 空 |
| ~0.69s | 出现 `版本开启时间 2026/10/15 版本更新维护后` + `LOADING DATA... 0%` |
| 1.1s → 5.5s | 计数 0% → 100%，约每 90–120ms 跳 1%；限速时 0% 停住约 19 秒（进度跟真实资源加载走） |
| ~5.8s | 加载屏卸下，骨架出现，左侧栏标签**逐项**淡入（0.3–0.35s `cubic-bezier(.22,1,.36,1)`，延迟 0.35 / 0.42 / 0.43 / 0.48s） |

**它为什么像终端，但它不是打字机**（[实测]）：加载屏里**没有任何文本节点** —— `LOADING DATA...` 是唯一的真文字，其余"日志"都在两张 PNG 里：

| 部件 | 窗口 | 图片 | 动画 |
|------|------|------|------|
| `code` | 110×53，`overflow:hidden` | `code.efef37.png` **110×468**（两行小灰字 + 大片透明） | `lheHI_ 10s linear 1`（通电闪烁） |
| `infoScroll` | 116×224（父窗口 `infoWindow` 116×112 裁剪） | `info.8349ef.png` **116×373** | `nOr1ah 33.003s linear infinite`（无缝竖向 marquee） |
| `dots` | 59×6 | 同一张 `code.efef37.png`（112×425） | 只淡入 |
| `infoBottom` | 116×61 | 同一张 `info.8349ef.png` | 淡入 |

三条 keyframes 的原文（[官方源码]，`version.css`）：

- `nOr1ah`（=`kf_876_1601_translate_0`）：`0%,3.03% translate(0)` → `27.27% translateY(-50%)` → `27.273% translate(0)` → 每 27.27% 段重复一次，`to` 停在 `-50%`。
  限速实测：`transform` 的 ty 从 `0` 走到 **−110.4px**（≈ 元素自身高 224 的 −50%）用 **8.1s**，然后**瞬回**，父窗口正好是 112px（图条的一半），所以接缝不可见 —— 这就是"日志在滚"的错觉来源。
- `lheHI_` / `T9s5_c` / `Xd4xM4`：`opacity 0 → 0 → .9 → .1 → .85 → .15（配 cubic-bezier(.22,1,.36,1)）→ 1`，即 **CRT 通电闪烁**；实测 `code` 条 0 → 0.19 → 0.99 → 1 用约 550ms。
- `jMT7n2` / `EblzwU`：淡入 + `translateX(var(--slide-x))` 滑入（加载屏所有部件都用这两条 + 各自延迟）。

**整屏构成**（[目视] `slow-02.png`，停住时的 10%）：满屏横向虚线（`lineTop` / `lineBottom` 各一条 1600×2）、巨号幽灵字 **`ENDFIELD INDUSTRIES`** 两行、一个巨大的同心圆、左侧装饰组（`verticalDecor` 40×294、`dots` 59×6、`code` 110×53、`shortLine` 4×27）与一条贯穿全高的竖向黄线（在面板图一侧，未单独对应到某个 DOM 节点）、小色标条、底栏 `版本开启时间 …` + 黄进度轨（`progressTrack` 1051×18 + `progressFill`）+ 右侧大号百分比。

**可以搬进皮肤的部分**（比上面表格里那批更"活"，但更需克制）：

1. **幽灵大字**（第二处证据，见 H）—— 这里用的是两行堆叠的 `ENDFIELD` / `INDUSTRIES`，比武器页那处更接近页标。
2. **满屏细虚线**：一行 2px 的 dash，横贯整个面板；皮肤可放在正文面板的上下沿。
3. **带刻度的竖黄线**：一条 2px accent 竖线 + 若干 40px 短横刻度；适合"当前回合"的滚动指示。
4. **"日志窗口"结构**：小窗口 + 内部无缝 marquee。**皮肤要用真文本做**（读得出来、能跟随语言与外观），不要学它烘焙成图 —— 顺带这也是版权上更干净的做法。
5. **通电闪烁**：只在新内容出现的那一刻闪一次（0.5–0.9s，opacity 抖 3 下），不要常驻；适合工具卡首次展开、新消息入场。

**不建议**：把百分比读成"进度条皮肤"（外壳没有这个部件）、照抄烘焙纹理（版权）、把闪烁做成循环（长时间盯着会累）。

## 3. 明确不建议抄的

- **页面美术与纹理**（角色立绘、`mask*`、`region-title-background`、`item_bg_*`、`item_rarity_texture_*`）：版权素材，皮肤自带资产必须是自绘（现有约定见 `assets/logo/`）。
- **字体** `HarmonyOS_Sans_SC`：系统字体，且与皮肤既有字体角色分工重复。
- **金色促销组件**（右下 `领取奖励` + 吉祥物）：页面运营件，不是 UI 语言。
- **圆形箭头按钮（`>` 圆底）**：本皮肤所有控件都直角，圆形只出现在"状态点"，不建议为它开口子。

## 4. 建议的落地顺序（含验证要求）

按"性价比 × 风险"排，每条都要求补上对应的检查，避免又一次"看着对、量出来不对"：

1. **B 虚线尺 + A 点状竖线**（纯 CSS，零新资产、零新设置）
   - 落点：decor 7（区块标题）与 decor 13（侧栏）；开关复用现有的 `Section marker`，不新增字段。
   - 验证：`verify-client` 加一条"虚线尺是伪元素、不占行高"的断言；live 加一条几何断言（尺的右端不越过标题盒）。
2. **C 数据总线 + D 渐变带**（两条都是"把已有带子/线换个画法"）
   - 落点：decor 12（工具卡头）、decor 14c/17（排队条与 todo 行底）。
   - 验证：live 量"dot 线的像素数 > 0 且不落在文字盒内"；渐变带的**首档不透明度**必须有断言（这条皮肤已有先例：composer seat 的不透明带）。
3. **H 文字型幽灵页标**（改动小、可见度高）
   - 落点：`settings.ts` 的 `MARK_PLATES` 增加一项 `text`，decor 18b 增加一条纯文本规则；`Artwork` 下拉自动多一项。
   - 代价：**新增设置字段要重启 `dsh web`**（宿主侧 schema 只在启动时读一次，已在 README「已知限制」里写明）。
4. **E 圆点节点行 + F 三色方块**（细节，等上面三条落地后再评估是否值得动）。

> 若要动手，建议一次只做 1 条并跑 `pnpm verify`；这个仓库的历史教训是"一次改多处、live 层才会告诉你哪条压不住外壳"。
