# 设计参考资料总览

本目录是 **Step 1（资料收集）** 的产物：为「终末地风格 DSH 皮肤」建立一份**可落地、可追溯、区分可信度**的设计参考。

## 资料的可信度分级

每一条结论都带来源标记，实现时请按此判断优先级：

| 标记 | 含义 | 例 |
|------|------|-----|
| **[官方源码]** | 直接从官方站点 CSS/JS/@font-face 提取，已验证 | `#FFFA00`（官方 CSS 出现 57 次）、`Novecentosanswide` |
| **[官方素材]** | 从官方素材文件取样或读取 SVG 属性 | `color-bar.png` 实测 `#FF1AAC / #01FFA2 / #FFFA00 / #D9D9D9`；`block-bg.svg` = 框 + 对角线 |
| **[官方文案]** | 官方公告/官网正文中的命名与写法 | `▼//版本全新内容`、`【嵌晶玉】×900`、`Chapter Ⅰ Process I` |
| **[社区分析]** | 玩家/设计师的分析文章（已注明出处） | CAT 黄黑白工业配色类比、等高线风格 |
| **[推断]** | 无直接证据，由前三类推导 | 危险色沿用 `#FF1AAC`；tooltip 外观 |

**已知空白（实现前建议补拍）**：未取得**游戏内 UI 的实际截图与调色板**（Game UI Database 无终末地条目且站内有反爬；Steam 无对应 appid）。因此「游戏内」相关描述以官网 + 官方公告 + 攻略站为主，已在 `02-ui-inventory.md` 标注。补拍路径见 `assets/README.md`。

## 三份文档怎么用

| 文档 | 用途 |
|------|------|
| `01-visual-language.md` | **风格层**：配色、字体、版式、图形母题、动效语言。做视觉决策时读它 |
| `02-ui-inventory.md` | **界面层**：终末地有哪些界面/组件，以及它们如何映射到 DSH 的 UI 部位 |
| `03-design-tokens.json` | **实现层**：机器可读令牌（颜色/字体/间距/圆角/边框/动效），可直接生成 CSS 变量 |

## 实现落点（给写代码的自己）

DSH Web GUI 的视觉层需要覆盖这些部件，下方是各自的终末地原型：

| DSH 部件 | 终末地原型 | 关键做法 |
|----------|-----------|---------|
| 应用底色 / 画布 | 工业深色画布 | `#191919` 打底；面板 `#2E2E2E` / `#35373C`；发丝线 `#191919`、`#999` |
| 顶部 / 侧边栏 | 官网 Header + 四角 HUD | 直角、无描边饰、`//` 前缀分区标题、按钮旁标注快捷键样式的小字拉丁标签 |
| 消息列表 | `Baker` 会话列表 + 官网 `noticeItem` 行结构 | 左类型标签条 + 主标题 + 右时间；行间 1px 发丝线 |
| 用户消息气泡 | 反白高亮 | 黑黄体系里「高亮」= **反白**（`#FFFFFF` 底 + `#000` 字），或 `#35373C` 底 |
| 输入框 / composer | 官网 Header 内联底槽 | `#242424` 底 + 细边框；光标与发送键 `#FFFA00`；`//` 或 `>` 前缀 |
| 工具调用卡片 | 技术框 + 角括号 | `block-bg` 母题：1px 框 + 对角线装饰 + 左上/右下角标 |
| 文件树 | AIC Facility List（俯瞰模式设施清单） | 折叠层级 + 行右状态条；末级名称用 `「」` / `【】` 包裹 |
| 终端 / 日志 | 个人终端 ProtoSync + `codePrinter` | 分区标题 `//`；prompt `#FFFA00`；stdout `#00FFA2`；打字机式逐行显现 |
| 弹窗 / 模态 | 官网 `ModalFrame` | **黑底上用 `#FAFAFA` 亮底弹窗**（最能与普通暗色皮肤拉开差距的一点）；居中标题 + 右上关闭 + 左下装饰辉光 |
| 设置面板 | `Settings_Menu` 三段结构 | label 行 + 右侧取值块；数字用宽体 `Novecentosanswide`；不可用项置灰 |
| 加载 / 骨架屏 | 官网 `__00-Loading` | 进度条填充 `#FFFA00`；`fadeIn .6s cubic-bezier(1,0,.7,1) .5s`；扫描/步骤初始化观感 |
| 状态色 | ⚠ 无官方语义色 | 成功 `#00FFA2`；警示/进行中 `#FFFA00`；错误 **[推断]** `#FF1AAC` |

> 提醒：DSH 客户端插件的实际接缝（客户端注入方式、CSS 覆盖点、令牌覆盖范围）需要按 `submodules/dsh-win-docker-workspace/docs/dsh-seam-notes.md` 与 DSH checkout 的实际声明确认 —— 本步只负责设计侧资料。
